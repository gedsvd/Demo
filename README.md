Deep Learning-Based Face DeepFake Image Detection System

Technologies: Python, Deep Learning, CNN, Computer Vision, Image Classification

Developed a lightweight Convolutional Neural Network (CNN) to detect DeepFake and manipulated facial images. Built an image classification model capable of identifying subtle visual artifacts introduced during image manipulation. Evaluated the model using benchmark datasets containing real and fake images. Achieved strong performance based on accuracy, precision, recall, and F1-score while maintaining low computational complexity. Designed the solution for efficient real-time digital forensic and information security applications. Demonstrated the effectiveness of lightweight CNN architectures for scalable DeepFake detection.
